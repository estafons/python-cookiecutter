Architecture

What the project assumes, and where responsibilities belong.

Main assumption

The architecture grows around tasks. A task owns the sample contract, the model output meaning, the loss, the metrics, and the outer loop.

What counts as a new task?

Create a new task when the learning problem itself changes.

  • the sample structure changes substantially
  • the target type changes
  • the model input/output meaning changes
  • the problem-level evaluation logic changes

Examples

  • item, label → classification
  • item, target → regression
  • item1, item2 → pairwise / matching

What usually does NOT require a new task?

  • changing the loss
  • changing metrics
  • changing the optimizer or scheduler
  • changing augmentation
  • changing batch collation
  • changing the backbone within the same prediction setup

Responsibility boundaries

main.py
Orchestration only: load config, initialize W&B, dispatch to the task
tasks/
Loop logic, losses, metrics, batch assumptions
models/
Architecture and forward contract required by the task
data/
Loading, preprocessing, normalization into task format
