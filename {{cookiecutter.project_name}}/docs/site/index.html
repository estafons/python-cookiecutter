What this documentation is for

This docs site explains a research project structure centered on task boundaries. It is designed to keep your codebase clean as you add new datasets, models, and experiments.

Rule of thumb: add a new model when the task stays the same, add a new dataset when the task format stays the same, and add a new task when the learning problem itself changes.
