Tutorial: Zero-shot MNIST with CLIP

A concrete first example: define the first task, add MNIST, add a CLIP zero-shot model, and create a named experiment.

Assumption for this tutorial: the project starts with no task defined yet. So the first task you add is classification.

Step 1: add the task config

Create configs/task/classification.yaml.

name: classification
label_field: label
input_field: image

Step 2: add the task logic

Create src/<package_name>/tasks/classification.py.

This file should own how batches are read, how scores are produced, and how accuracy is computed.

Step 3: add the dataset config

Create configs/data/mnist.yaml.

name: mnist
task: classification
builder: mnist
num_classes: 10
class_names:
  - zero
  - one
  - two
  - three
  - four
  - five
  - six
  - seven
  - eight
  - nine

Step 4: add the dataset loader

Edit src/<package_name>/data/factory.py and add an mnist branch.

Normalize samples to something like:

{
    "image": image_tensor_or_pil,
    "label": int_label,
}

Step 5: add the model config

Create configs/model/clip_zeroshot_classifier.yaml.

name: clip_zeroshot_classifier
builder: clip_zeroshot_classifier
pretrained_model_name: openai/clip-vit-base-patch32
prompt_template: "a photo of the digit {}"

Step 6: add the model implementation

Create src/<package_name>/models/clip_zeroshot_classifier.py.

This model should:

  1. load pretrained CLIP
  2. encode the class prompts once
  3. encode the image
  4. compute image-text similarity
  5. return scores over the 10 class names

Step 7: register the model

Edit src/<package_name>/models/factory.py.

Step 8: register the task dispatcher

Edit src/<package_name>/run.py so that it calls run_classification(cfg) when cfg.task.name == "classification".

Step 9: add a named experiment

Create configs/experiment/mnist_clip_zeroshot.yaml.

# @package _global_

defaults:
  - override /task: classification
  - override /model: clip_zeroshot_classifier
  - override /data: mnist

tags: ["mnist", "clip", "zeroshot", "classification"]

Run it

python main.py experiment=mnist_clip_zeroshot logger=wandb

Because the template defaults to offline/local W&B mode, this logs locally unless you explicitly set WANDB_MODE=online.

What you do not need to change

  • main.py should stay orchestration-only.
