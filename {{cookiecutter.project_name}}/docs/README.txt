This bundle contains:

1. mkdocs.yml + docs/ markdown sources
   - suitable as a starting point for a MkDocs site

2. site/ static HTML pages
   - open site/index.html directly in a browser

Suggested next step if you want a real MkDocs workflow:

    pip install mkdocs-material
    mkdocs serve

and then open the local URL shown by MkDocs.
